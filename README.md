# Modelagem Analítica e Numérica do Problema de Dois Corpos

Este repositório contém o código-fonte computacional e os scripts de visualização do projeto **"Modelagem Analítica e Numérica do Problema de Dois Corpos"**.

## 📌 Descrição
Simulação numérica do sistema Sol-Terra desenvolvida em Python com a biblioteca [REBOUND](https://rebound.readthedocs.io/), validando analiticamente as Leis de Kepler e a conservação dos elementos orbitais.

## 👨‍💻 Autores
* Alunos do Colégio Fonte
* Orientadores (UNESP / Colégio Fonte)

## 📁 Arquivos
* `simulador_dois_corpos.py`: Código principal em Python.
* `orbita_2d_3d.png`: Gráfico da trajetória em 3D e projeção 2D.
* `elementos_orbitais.png`: Gráficos dos elementos orbitais osculadores.
